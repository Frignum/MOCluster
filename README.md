# MOCluster
Выявление экономической структуры российских муниципалитетов с использованием кластеризации на атрибутированных сетях.  

Мы собрали данные с сайтов Росстата и СберИндекса, обработали их и кластеризовали Муниципальные Образования по различным признакам

## Описание признаков
- region_name : Название региона
- mo : Муниципальное образование
- year : Год замера
- month : Месяц замера
- Здоровье_share, Маркетплейсы_share, Общественное питание_share, Продовольствие_share, Транспорт_share Ж доля определенных категорий безналичных расходов в общих безналичных расходах
- urban_share : процент городского населения
- Средняя зарплата
- population : население

## Как использовать
В файле dataset_preparation.ipynb лежит предобработка сырых датасетов Росстата и СберИндекса. Изначальные датасеты, так же как и итоговый датасет df_sberne.csv лежат в папке datasets. В файле experiments.py выбирается resolution и метод проведения ребер. В файле clustering.py проводится кластеризация.
